# Tienda de Don Jairito - Python

Simulador de un sistema de ventas básico para una tienda de barrio. 

## Funcionalidades
- Gestión de inventario mediante diccionarios.
- Carrito de compras dinámico.
- Cálculo automático de subtotales y total.
- Validación de pagos y cálculo de cambio (vuelto).
- Manejo de errores (Excepciones) para entradas inválidas.

## Tecnologías Usadas
- **Lenguaje:** Python 3
- **Conceptos:** Bucles anidados, Control de excepciones, Estructuras de datos.
